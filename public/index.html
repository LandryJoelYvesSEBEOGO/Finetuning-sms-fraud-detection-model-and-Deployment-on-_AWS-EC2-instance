    How it works

    1. Paste

      Paste an English SMS. Messages are analyzed on the fly, never stored or logged.

    2. Analyze

      DistilBERT fine-tuned with LoRA reads the message, served with ONNX Runtime in milliseconds.

    3. Decide

      You get a fraud score from 0 to 100%, compared with an alert threshold.

    About this demo

    This is a proof of concept. The model (DistilBERT fine-tuned with LoRA on English SMS) can be wrong in both directions: never rely on it alone, and never share codes, passwords or bank details by SMS.
